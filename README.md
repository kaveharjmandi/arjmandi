# آریانا (Ariana) - گردش مالی خانواده

اپلیکیشن مدیریت مالی، حسابداری و گردش وجوه خانواده بر پایه کاتلین و Jetpack Compose برای سیستم‌عامل اندروید.

## قابلیت‌های کلیدی

- **داشبورد اصلی (خانه)**:
  - کارت بانکی هوشمند با نمایش موجودی لحظه‌ای و دکمه مخفی‌سازی
  - تفکیک موجودی حساب هر یک از اعضای خانواده
  - دکمه جابجایی بین حساب‌ها
  - کارت آمار مجموع واریزی‌ها و برداشتی‌ها
  - نشانگر پیوستگی و رکورد ثبت روزانه (Streak)
  - دسترسی سریع به آخرین تراکنش‌ها

- **مدیریت تراکنش‌ها**:
  - ثبت واریز (+) و برداشت (−) با امکان تقسیم بین دسته‌بندی‌ها
  - تقویم شمسی (جلالی) اختصاصی برای ثبت تاریخ دقیق
  - جستجو و فیلترهای پیشرفته بر اساس شخص، حساب و نوع تراکنش

- **ریز حساب هر شخص**:
  - گزارش بر اساس بازه‌های زمانی روزانه، هفتگی، ماهانه و سالانه
  - تفکیک دخل‌وخرج هر عضو خانواده

- **دفترچه چک‌ها**:
  - مدیریت چک‌های پرداختی و دریافتی
  - وضعیت‌های سررسید، پاس شده، برگشت خورده و باطل شده همراه با هشدارهای زمان سررسید

- **اهداف، وام‌ها و بدهی‌ها**:
  - جیب‌های پس‌انداز با درصد پیشرفت
  - مدیریت اقساط وام و قراردادهای اجاره مسکن
  - ثبت طلب و بدهی بر اساس تومان یا گرم طلای ۱۸ عیار

- **امنیت و تنظیمات**:
  - قفل سریع با پین‌کد (PIN)
  - پشتیبان‌گیری و بازیابی داده‌ها به فرمت JSON
  - پنل مدیریت اعضای خانواده، دسته‌بندی‌ها، تراکنش‌های تکراری و بودجه ماهانه
  - پشتیبانی کامل از تم‌های روشن و تاریک (Dark Mode / OLED) و چیدمان راست‌به‌چپ (RTL)
